# Support

Thanks for using the GPAT Mock Test Portal! 👋

## Documentation

- Start with the [README](README.md) — setup, configuration, deployment.
- [CONTRIBUTING.md](CONTRIBUTING.md) covers the development workflow.

## How to Get Help

| Channel | Best for |
|---|---|
| [GitHub Issues](https://github.com/svsk1977/my-mocktest-app/issues) | Bugs, feature requests, question-bank contributions |
| [GitHub Discussions](https://github.com/svsk1977/my-mocktest-app/discussions) | Q&A, usage help, showing off your deployment |

Before opening a new issue, please **search existing issues** — your question
may already be answered.

## How to Report a Bug

Open an issue using the
[bug report template](.github/ISSUE_TEMPLATE/bug_report.md) and include your
environment, steps to reproduce, and expected vs actual behavior.

## Response Expectations

This project is maintained by volunteers in their free time. Most issues get
a first response within a few days. Please be patient and kind. 💚
