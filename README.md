GPAT 25 Mock Tests Portal
This application is a dedicated online portal for students to attempt multiple-choice question (MCQ) mock tests, designed primarily for competitive exams like GPAT. It provides a timed, structured environment to practice and evaluate preparation.
Features
* Secure Login: Access your test history and active mock tests via a dedicated login.
* Timed Examination: A running timer visible during the test ensures practice under exam conditions.
* Navigation Panel: A quick-view panel to track answered, unanswered, and reviewed questions.
* Question Status Indicators: Color-coded status for easy monitoring of progress.
* Test Finalization: Clear completion message upon submission.
How to Take a Mock Test
1. Login and Access Tests
1. Navigate to the portal URL (e.g., svcp mocktest.streamlit.app).
2. On the welcome screen, enter your registered Email and Password in the "Login to Mock Test Portal" section.
3. Click the Login button.
4. Once logged in, you will be directed to the main interface, which displays two tabs: Instructions and Tests.
2. Review Instructions
Before starting, click on the Instructions tab to review the mandatory rules for attempting the test:
* Click on the Tests tab to begin the test attempt process.
* You will find the Start Test option once the countdown reaches zero (if applicable).
* DO NOT refresh or close the tab after clicking Start Test.
* After selecting an option, you must click Save Answer to confirm the choice or Save for Review to mark it for later reconsideration.
3. Start the Test
1. Go to the Tests tab.
2. Active mock tests will be clearly indicated (e.g., "Mock Test 2 is now live!").
3. Click the Start Test button below the test you wish to attempt.
4. Navigating and Answering Questions
Once the test begins, the screen is split into the question area and the navigation panel:
Navigation Panel (Left Side)
This panel shows the status of every question in the test:

	Meaning

	You can click any question number in this panel to jump directly to it.
Question Area (Center)
1. Time Left: The remaining time for the test is clearly displayed at the top right (e.g., 00:07:00 in the recording indicator and 2 min 43 sec visible on the screen).
2. Answering: Read the question and select one of the radio buttons corresponding to the answer options.
3. Action Buttons:
   * Previous / Next: Navigate between questions.
   * Save Answer: MANDATORY to confirm and save your selected option. The question status will turn Green.
   * Change Answer: Use this to clear your current selection and choose a different option.
   * Save for Review: Saves your current answer but marks the question as Yellow. This allows you to submit the answer if time runs out, but reminds you to revisit it later.
5. Final Submission
1. The test will automatically finalize when the timer runs out.
2. You can also submit the test manually once you are satisfied with all your answers.
3. Upon submission, a final message will confirm: "Test Completed! Thanks for attempting."
4. Your results will then be finalized and saved.
